# Teach a robot your dance

Static website for the "Teach a robot your dance" workshop on motion retargeting and robot learning, hosted by the Advanced Telerobotics Research (ATR) Lab, Department of Computer Science, Kent State University. It is plain HTML and CSS (`index.html` plus images in `assets/`), with no build step, served by GitHub Pages from the `main` branch at https://kyk0.github.io/robot-dance-workshop/. To change the date, time or place, edit the block marked `EVENT DETAILS` near the top of `index.html` and push to `main`.
